# Cauldron Rumble — submission copy

## Short description

Build a magical cauldron, merge ingredients and master powerful synergies in a
compact fantasy autobattler.

## Description

Choose ingredients, combine matching items into stronger versions and create a
build around Fire, Poison, Guard, Frost or Echo. Your cauldron fights
automatically, but every purchase, reroll and family combination shapes the
outcome. Complete two handcrafted campaigns, adapt to unusual opponents and
defeat each campaign boss.

## Controls

- Mouse: click buttons, ingredients and item slots.
- Touch: tap buttons, ingredients and item slots.
- The battles resolve automatically.

## Package profile

- HTML5 static game
- Desktop and mobile browser support
- English and German language selection
- Local save progress
- CrazyGames Basic Launch package (no SDK or ads yet)
